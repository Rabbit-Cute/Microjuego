# Microjuego - Asteroids

A simple 2D arcade game where you control a spaceship and shoot incoming asteroids.

## 🛠️ Built With
*   **Engine:** Unity
*   **Language:** C#

## 🎮 How to Play
1. Go to the **Releases** section on the right side of this repository.
2. Download the `.zip` file.
3. Extract the files and run the `.exe` to play.
